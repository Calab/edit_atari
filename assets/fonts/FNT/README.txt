ATARI FONTS (.FNT)

Fonts to use in Edit Atari (Options > Fonts). Each is 1024 bytes: 128
characters of 8 bytes, in the order of the Atari's character set ROM, as
Atari font editors save them.

  BIG.FNT       Standard character set
  BIGINTL.FNT   International character set (the set F6 switches to)
